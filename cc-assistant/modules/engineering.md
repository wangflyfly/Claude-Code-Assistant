# 模块 10：工程化（engineering）

> 从「会用」到「用得好」：成本、安全、指令、协作四要素。核心主题 = 工程化实战。

## 是什么 / 何时用

- **成本控制**：真实成本 = API 成本 + 人力时间成本。控制输出（输出价高于输入）、按需选模型、提高缓存命中、`--max-budget-usd` 硬兜底。
- **安全**：最小权限是底线。权限模式 deny→ask→allow；`permissions.deny` 禁读敏感文件；密钥放环境变量 + 不进 Git + deny 禁读 + Hook 拦截四层防护。
- **指令**：写好 CLAUDE.md 与 prompt——量化、示例驱动、明确边界（范围/工具/依赖/失败都定义「禁止项」）。
- **协作**：`.claude/` 共享策略（共享与非共享清单）；团队规则走 PR 审查；受管设置做组织级强制。

**何时用（触发判据，D12）**：关注成本/安全/指令/协作任一维度 → 走工程化；任务涉及敏感数据或预算 → 先配好安全与成本护栏。

## 场景演示

- 从学习者项目里找一个工程化切入点（如一次成本审视、一处安全薄弱点、一段待规范化的指令）。
- 演示成本审视：哪些调用在烧钱、如何用护栏与模型分层控制。
- 讲安全最小权限：当前项目的权限配置是否过宽、敏感文件是否暴露。

## 真实轻练习

- 学习者在自己的项目里做一次真实工程化练习（成本审视 / 权限收紧 / 指令规范 / 协作约定，选一项），并落下一个可验证的小改动（REQ-PME-001）。
- 交互模型（D13）：由学习者动手；卡住给提示方向；不代做。
- 小而可逆（REQ-PME-004）：配置/文档类改动可回退；权限收紧先给学习者确认（SFT-004）。

## 高阶深入实操（可选，phase=高阶时进入）

- 高阶阶段（REQ-TPT-002）深化：跨维度综合——在一个真实场景里同时做成本护栏 + 权限收紧 + 指令沉淀 + 团队协作约定，形成工程化方案。
