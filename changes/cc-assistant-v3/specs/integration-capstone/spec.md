# Spec: Integration Capstone（收官整合）

## ADDED Requirements

### Requirement: REQ-ICN-001 跨模块综合真实任务
系统 MUST 在收官整合模块引导学习者完成一个跨模块综合真实任务，任务需组合 2+ 种 Harness 机制（如记忆系统 + Hooks，或 Skills + MCP）。

#### Scenario: 综合任务组合多机制
- **WHEN** 学习者进入收官整合模块
- **THEN** 系统给出/引导选定一个需组合 2+ 机制的真实任务，作为综合练习载体

#### Scenario: 任务在学习者项目内进行
- **WHEN** 综合任务开始
- **THEN** 任务作用于学习者的真实项目，沿用之前模块的同一项目

### Requirement: REQ-ICN-002 独立完成并说出选型理由
系统 MUST 让学习者独立完成综合任务，并对其选用的机制组合说出选型理由（为什么用 A 不用 B）。

#### Scenario: 学习者独立组合机制
- **WHEN** 学习者完成综合任务
- **THEN** 其独立完成（skill 只引导与核对），并能说出所选机制组合及理由

#### Scenario: 说不清选型理由
- **WHEN** 学习者完成任务但无法说明选型理由
- **THEN** 系统回到相关机制的教学点补讲，再让其复述理由

### Requirement: REQ-ICN-003 体系讲解按书框架复用边界
系统 MUST 在收官整合中做体系讲解（四层架构 / 触发口诀 / 关注点分离 / 选型决策树），并按「书框架复用边界」改写为自有表达并归因，不内联书原文。

#### Scenario: 体系讲解改写归因
- **WHEN** 系统讲解四层架构/触发口诀等书原创框架
- **THEN** 用课程自有表达改写并归因来源（不整段照抄、不保留原章节结构/句式），把进阶讲成体系

#### Scenario: 不内联书原文
- **WHEN** 审查收官整合交付内容
- **THEN** 不含书原文整段表述；超出课程自有改写的参考内容走 claude-code-guide / 官方文档
