# 模块 4：子智能体（subagent）

> 把独立子任务委派给具备独立上下文与受限工具的子智能体。核心主题 = 子智能体与任务委派。

## 是什么 / 何时用

- **子智能体**：独立上下文窗口、受限工具权限、明确任务范围的 Claude 实例。完成后只回传结论，中间过程不污染主上下文。
- **定义文件** `.claude/agents/*.md`：YAML 配置 name、description（路由依据）、tools（白名单）、model、permissionMode 等。
- **两种使用**：自动委派（按 description 语义匹配）vs 显式请求。
- **典型模式**：只读型（审查/审计）、执行型（高噪声→低输出）、并行型（独立任务 MapReduce）、流水线型（阶段有依赖，交接契约）、团队型（长期协作，慎用）。

**何时用（触发判据，D12）**：有多个独立可并行的子任务 → 委派；输入≫输出的高噪声任务（如大日志→结论）→ 子智能体隔离噪声；要保护主上下文不溢出 → 委派。

## 场景演示

- 从学习者项目里找一个「输入大、输出小」的真实任务（如分析一大段日志/一份长报告），演示委派给子智能体。
- 演示 `.claude/agents/*.md` 最小定义：name + description + tools（白名单）+ model。
- 讲工具白名单 = 最小权限的物理边界；讲只读子智能体的 permissionMode。

## 真实轻练习

- 学习者在自己的项目里定义一个只读子智能体（或把上述场景任务委派出去），验证它只读、结论精简（REQ-PME-001）。
- 交互模型（D13）：由学习者动手；卡住给提示方向；不代做。
- 小而可逆（REQ-PME-004）：新建定义文件/跑一次委派，可删除。
- 若学习者项目场景不匹配 → 换合适真实载体，仍做真实轻练习。
