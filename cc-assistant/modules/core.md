# 模块 1：核心能力（core）

> 课程第一个模块：让学习者能安全、有效地给 Claude 下指令、审阅改动、用核心命令、配好 CLAUDE.md。继承 v2 核心教学（REQ-COR-001~005）。just-in-time，不预灌。

## 是什么 / 何时用

- **下指令**：Claude 按你给的指令做事。指令模糊 → 结果偏离预期。把指令说具体（目标、涉及文件范围、验收标准）能显著提高质量。
- **审阅改动**：AI 产生 diff 后由你决定接受/拒绝。盲目全量接受会引入你不了解的改动。
- **核心命令**：`/help`（求助）、`/clear`（清上下文）、`@文件`（引用具体文件）按需使用，非穷尽。
- **CLAUDE.md**：项目的长期记忆文件，每次会话自动加载，让 Claude 记住项目约定。
- **Plan Mode**：任务较大需先规划时用（何时用/怎么用/与直接执行的区别），普通任务不强行引入。

**何时用（触发判据，D12）**：首次下指令或指令模糊 → 教改具体；第一次见 AI diff → 教审阅；对命令/上下文/文件引用困惑 → 按时刻教 `/help` `/clear` `@文件`；完成首个任务 → 教 CLAUDE.md；任务较大需先规划 → 教 Plan Mode。

## 场景演示

- 让学习者在自己的项目里下一个真实指令；若模糊，演示如何改成「目标 + 文件范围 + 验收标准」三要素（REQ-COR-001）。
- 产生第一处改动时，展示 diff 怎么看、如何接受/拒绝单处、为何不盲目全量接受（REQ-COR-002）。
- 若学习者表达困惑 → 在该时刻讲对应核心命令（REQ-COR-003）。
- 完成后讲 CLAUDE.md 作用并演示模板，写入与否由学习者决定（REQ-COR-004 / SFT-004）。
- 若当前任务较大需规划 → 讲 Plan Mode 并在该任务演示（REQ-COR-005）。

## 真实轻练习

- 学习者在自己项目里下一个具体指令（含三要素），跑通一个「下指令 → 审阅 → 接受/拒绝」的小闭环（REQ-PME-001/003）。
- 交互模型（D13）：练习由学习者动手；卡住先引导自己尝试，必要时才给最小提示；学习者请求代做 → 拒绝并给提示方向。
- 小而可逆（REQ-PME-004/SFT-001）：练习操作可撤销，不会造成不可恢复副作用。
