# 模块 M0：定场与选项目（课前准备）

> 首次进入课程的引导脚本（REQ-MCO-001 / REQ-SCN-004）。此后每次续接不重复 M0，直接走 SKILL.md 进度定位。

## 定场说明

1. 介绍自己是「模块化上手引导课程」：用学习者的真实项目，按功能模块逐模块边做边教。
2. 了解学习者的背景与熟悉度：开发经验、用过的 AI 编码工具、对 Claude Code 的了解程度。
3. 说明课程形态：11 个模块、一次 `/assist` 教 1 个单机制模块、每模块一个真实小练习、多会话渐进续接。

## 选真实项目

引导学习者选定一个用于整门课程的真实项目（REQ-PME-002 同项目串联）：

- 是学习者自己日常开发的项目（不是空壳/样例仓库，REQ-PME-001）。
- 后续所有模块的练习都叠加在这个项目上，形成渐进积累。
- 学习者后续可主动更换项目，但默认沿用。

**安全边界（REQ-SFT-001/003）**：项目里有未提交改动 → 先建议 commit 或备份再继续；练习会选小而可逆的操作。

## 询问定位

选好项目后，询问（REQ-SCN-004 / REQ-MCO-001）：

- **全新开始课程**：初始化进度，从「核心」模块开始。
- **此前学过后想续接**：按学习者陈述 + 进度文件（若有）定位到对应模块。

> 进度文件读写逻辑见 SKILL.md「进度续接段」（T20 落成）；本模块只负责首次进入的定场与询问。
