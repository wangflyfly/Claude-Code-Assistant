+# 模块 11：收官整合（capstone）
+
+> 课程的最后一环：把前面 10 个模块学到的机制组合起来，做一个跨模块综合任务，并把各机制的定位讲成体系。本模块为多会话综合阶段（REQ-MCO-003），可拆多次 `/assist` 完成。
+
+## 是什么 / 何时用
+
+- **收官整合**：综合运用前面学过的 2+ 种 Harness 机制，在一个跨模块真实任务里协同工作。
+- **体系讲解**：把各机制的职责边界与协同方式讲成体系（四层架构 / 触发口诀 / 关注点分离 / 选型决策树），帮助学习者从「会用单个机制」升级为「知道何时用哪个、怎么组合」。
+
+**何时用（触发判据，D12）**：课程进入收官整合模块 → 综合任务 + 体系讲解；前面模块未完成时先走续接补齐，不跳过必修模块。
+
+## 场景演示
+
+- **综合任务**：从学习者项目里引导选定/给出一个需组合 2+ 机制的真实任务（如「记忆系统 + Hooks」配置一个带质量门控的项目，或「Skills + MCP」做一个带外部数据的自动化流程）。任务沿用之前模块的同一项目（REQ-ICN-001）。
+- **体系讲解（改写归因）**：把机制分层讲成体系——记忆层（CLAUDE.md 让模型不失忆）、扩展层（Commands/Skills/子智能体/Hooks 扩展能力）、集成层（MCP/Headless 连接外部）、编程层（Agent SDK 构建应用）；触发口诀（手动叫它 / 它自己知道该做 / 安排别人做 / 到这一步就检查）；选型决策树（按场景选组件）。以上体系框架源自《Claude Code 实战》黄佳（人民邮电出版社），此处为课程自有改写并归因，不保留原文表述（REQ-ICN-003）。
+- 讲关注点分离：CLAUDE.md「知道什么」、Skills「怎么做」、子智能体「谁来做」、Hooks「能否做」，边界清晰才能自由组合。
+
+## 真实综合练习
+
+- 学习者独立完成综合任务：组合 2+ 机制，自己决定用哪些机制、怎么组合；skill 只引导与核对，不代做（REQ-ICN-002 / D13）。
+- **说出选型理由**：任务完成后，学习者需说出「为什么用 A 不用 B」（理由涉及所用机制的适用条件）。说不出 → 回到相关机制教学点补讲，再让学习者复述（REQ-ICN-002）。
+- 综合任务可拆多次会话完成，每次记录进度（REQ-MCO-003）。
+- 小而可逆（REQ-PME-004/SFT-001）：综合任务也选可逆操作；危险操作先征得同意（SFT-002）；落地由学习者决定（SFT-004）。
+
+## 高阶综合项目（可选，phase=高阶时进入）
+
+- 进阶阶段完成上面综合任务 + 体系讲解即为收官。高阶阶段（REQ-TPT-002）：做更大的综合项目，深度组合机制（如 Agent SDK + Hooks + MCP 的完整产品化流程），并独立完成选型与工程化落地。
+
+## 交叉引用
+
+- 参考类（机制最佳实践）：**REQUIRED SUB-SKILL:** claude-code-guide。
+- 官方文档（未覆盖时）：引用 docs.anthropic.com。
+- 体系框架来源：黄佳《Claude Code 实战：Harness 工程之道》（人民邮电出版社，2026）——本模块体系讲解为课程自有改写并归因，未内联书原文。
